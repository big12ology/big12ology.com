Privacy

Last updated: August 2, 2026

Big12ology is a personal fan project — static websites about Big 12 football. The short version: no accounts, no cookies, no ads, no selling of anything, and as close to no data as a website can get.

What these sites collect

  • Nothing you type. There are no forms, sign-ups, or comment boxes.
  • No cookies, no local storage. Interactive features (like the tiebreaker what-if simulator) run entirely in your browser's memory and forget everything when you close the tab.

Hosting

The sites are served by GitHub Pages. Like most web hosts, GitHub may log visitor IP addresses for security and operational purposes; see the GitHub Privacy Statement. DNS is provided by Cloudflare.

Analytics

These sites use (or may use) Cloudflare Web Analytics, a privacy-first measurement tool: no cookies, no persistent identifiers, no fingerprinting, and no cross-site tracking. It gives us aggregate counts (page views, referrers, countries) and nothing about you as an individual.

External links and data sources

Links to other sites (GitHub, collegefootballdata.com, big12sports.com, and others) are governed by those sites' own privacy policies. Game data is fetched by our build servers, not by your browser.

Changes and contact

If this policy changes (for example, if analytics tooling changes), this page will be updated with a new date. Questions: dept@big12ology.com.

Big12ology is not affiliated with the Big 12 Conference.
